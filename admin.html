Nueva plantilla

Rellena los datos. El "Link del editor" es la URL del repo donde vive el HTML de esa plantilla.

¿Cómo obtener este link?
1. Crea un repo nuevo en GitHub
2. Sube tu index.html con el editor
3. Settings → Pages → main / root → Save
4. Espera 2 min y copia la URL aquí
